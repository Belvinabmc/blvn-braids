# Blvn-braids
plateforme de reservation en ligne le salon de coiffure blvn-braids 


##  Objectif

Permettre aux clientes de consulter les prestations, choisir un créneau disponible et réserver une prestation de coiffure en ligne.

L'application permettra également à l'administratrice de gérer les prestations, les réservations, les horaires et les clientes.

## Stack technique

### Front-end
- React

- React Router
- Axios

### Back-end

- Django REST Framework
- JWT

### Base de données
